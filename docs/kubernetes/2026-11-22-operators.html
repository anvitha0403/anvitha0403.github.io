Kubernetes Operators

Topic: Kubernetes Last Updated: 2026-11-22 Status: Learning Tags: operator, controller, crd, kubebuilder

One-Line Summary

An Operator extends Kubernetes by introducing custom resources and a controller that automates operational tasks.

Why Do Operators Exist?

Kubernetes knows how to manage Pods, Deployments, StatefulSets, Services, etc. It does not know how to manage a PostgreSQL cluster, Kafka cluster, or Redis cluster. Operators teach Kubernetes how to manage these systems.

Problem Operators Solve

Without operators:

  • Manual backups
  • Manual failover
  • Manual scaling
  • Manual upgrades

Operator automates these actions.

Core Concepts

CRD (Custom Resource Definition)

Introduces a new Kubernetes resource. 


kubectl get postgresql

"postgresql" exists only because a CRD was installed.

Custom Resource (CR)

Actual instances of the CRD. 


apiVersion: db.example.com/v1
kind: PostgreSQL
metadata:
  name: primary
spec:
  replicas: 3

Controller

Continuously compares desired state with actual state.

Mental Model

Deployment Controller manages Pods. Operator is just another controller that manages higher-level resources. Deployment -> Pod PostgreSQL Operator -> PostgreSQL Cluster

Reconcile Loop

Operator pattern: 


while(true) {
    actual = observeCluster()

    desired = readSpec()

    if(actual != desired) {
        fixCluster()
    }
}

Everything revolves around reconciliation.

Interview Questions

What is an Operator?

A controller that watches custom resources and performs domain-specific automation.

Difference Between CRD and Operator?

CRD defines a new resource type. Operator contains business logic for managing that resource.

Can I Have a CRD Without an Operator?

Yes. The resource exists but nothing reacts to it.

How Is an Operator Different From a Deployment?

Deployment manages stateless applications. Operators usually manage stateful or complex systems.

Personal Understanding

Operator = Deployment Controller, but for my own resource. Kubernetes provides generic controllers. Operators let us write custom controllers.
